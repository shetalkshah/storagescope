# StorageScope

StorageScope is a source-backed dashboard for U.S. self-storage industry trends. It covers national pricing, occupancy, market momentum, supply, capital markets, competitive structure, and source methodology.

## Scope

The dashboard uses market and industry evidence compiled from six supplied reports. Company financial statements, FFO, NOI, debt, dividends, stock performance, and company-specific profitability metrics are excluded.

## Dashboard sections

- Executive overview
- Pricing and revenue
- Demand and occupancy
- MSA markets
- Supply pipeline
- Capital markets
- Market structure
- Sources and definitions

## Local use

Open `index.html` directly or serve this directory with any static web server.

## Data

The compiled CSV files are in `data/`. The dashboard also includes an embedded snapshot in `data.js` so it can run reliably as a static site.
